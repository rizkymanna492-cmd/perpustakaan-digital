# Panduan Deploy untuk Tugas Kampus

## 1. Buat akun Supabase
- Daftar di https://supabase.com
- Buat project baru

## 2. Jalankan SQL
- Buka SQL Editor di Supabase
- Salin isi file supabase-schema.sql
- Jalankan query

## 3. Isi konfigurasi
- Buka supabase-config.js
- Ganti URL dan anon key dengan nilai dari project Anda

## 4. Deploy ke Netlify
- Upload project ke GitHub
- Import repository ke Netlify
- Publish directory: .

## 5. Tes
- Buka link Netlify
- Login dengan admin/admin123
- Tambahkan buku
- Coba fitur baca buku
