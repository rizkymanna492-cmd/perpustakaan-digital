# Perpustakaan Digital

Aplikasi perpustakaan sederhana yang dapat dijalankan sebagai website ringan.

## Fitur
- Login admin dan user
- Tambah buku
- Upload cover dan file ebook
- Simpan data di browser (localStorage)

## Catatan
- Untuk data yang lebih permanen dan bisa dibagi antar perangkat, perlu koneksi database.
